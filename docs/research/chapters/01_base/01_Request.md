# Initial Research Request

We need in-depth plan on how to implement using Go lang as main programming language the comprehensive System for game playing! System MUST have APIs (REST, Events SSE, Websockets, etc) client apps - Desktop, Mobile, Web, TV (Android TV). The point of the whole project is the following. Main HOST contains computer games installed. We have macOS, Linux and Windows host machines. Each Game can be played using keyboard, mouse or gamepad (joystic) controllers. HOST machine is not pharisaically present in same space where players are!
Player opens client app on its device, to his device via USB or some wireless interface he has paired Gamepad, Hoystick, Keyboard, Mouse, etc. User browses the 'catalog' of installed games on HOST machines, chooses one and starts it. Game loads, starts and user is playing it using paired controllers. All user's controller commands are transmitted with zero lag to remote HOST machine into the computer game, all graphics is rendered for the user full-screen with zero lag, highest set resolution and maximal possible refresh rate (MHz)! UX for the user on client device / app is the same as on PS4 Pro. Pressing the home button sends user to main catalog of games / landing screen, user can chose and play some other game while the one which is already open is dismissed safely without data or system corruption! Client apps MUST have main landing screen like PS4 Pro does, opening the catalog (library) and browsing games, sorting and filtering by various parameters. For every game 4K covers and screen-shots MUST be obtained so everything looks nice and smooth! For the front-end we would like if possible everything to be as much as possible done in Go lang with possibility of use on top of it Angular, Tauri, even Flutter or Kotlin Multi-Platform. It is required in-depth research to be created! We need in-depth plan of development, all technical challenges analysed and properly addressed, every technical decision multiple times checked and verified. Plan MUST be divided into phases with fine-grained tasks and step by step implementation guide(s) up yo the smallest point! The whole system MUST BE fully scalable - APIs and Client apps as well! We need additional technical documentation too - wireframes, diagrams, and comprehensive Figma or Penpot design (with Wireframes)! We MUST have the possibility to customizable themes (color schemes) and screen layouts! We MUST be able to white-label the System for end-users so they can have its own brand, logo, color scheme (day and dark) and other common customization(s) available.
