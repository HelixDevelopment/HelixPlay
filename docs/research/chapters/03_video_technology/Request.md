# Video technology use for gaming platform

We are building further on top of this all we have created!
Next deep research we MUST do is on video technology we can use for video stream playback, recording, keeping stored recordings (safe).
We need ultra high resolution video codecs which will make possible to stream real time gaming content with no latency from gaming machines.
Stream MUST be possible to record - if user wants its gaming sessions to be recorded in real time while he is playing that MUST be possible and the following conditions MUST meet:
- No frames loss
- No playback or game experience affected
- No latency or lags brought into the system / session
- Same high number of frames per second
- Recording to custom (configurable) storage: SMB / NFS / FTP / WebDAV / Custom pipeline - for live streaming and other possibilities
All this MUST BE full satisfied for audio! Full AC3 support, Dolby and other main stream types! Audio MUST be recorded as well in real time with highest possible quality!
Audio MUST work with standards, PCM, Stereo, 5.1, 7.1 and others! EVERYTHING MUST BE HiFi bleeding edge optimized!

For this to work we must use all possibilities offered by the hardware on gaming machines, middleware (we may need this!!!) and client applications!
We MUST be able to detect power features of hardware and OS of the systems running the components!
This all MUST be dynamic, however in worst case scenario so heavy optimized that on worst possible configurations everything still works:
- With no lags
- No glitches (audio or video), lost frames, interruptions
- Any kind of ANRs or crashes
- Overheating of system computers / hosts / machines / hardware components
- No latency (bare minimum)
- Maximal use of hardware layer(s) !!!

Everything MUST heavily be covered with the tests! 100% coverage and definition of proper testing strategy which can verify and validate every piece of the system!
We need comprehensive step by step research document divided in all incorporating and implementing phases! Up to the component and the line of code with exact examples and solutions!
All bottlenecks MUST be properly identified and viable solutions chosen to handle these!
It is required ultimate and full documentation for everything, user guides, manuals, diagrams, schemes and proper and full references!
We MUST BE innovative and rely to new achievements in opensource, advanced articles that are covering this area, scientific posts! They ALL MUST be processed and properly used for the the cutting-edge implementation we need!
